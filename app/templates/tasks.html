📚 API Endpoints

Метод Endpoint Описание Параметры
POST /api/tasks Создание новой задачи title, description, category, status, priority, location_id, created_by, assigned_to, due_date, attachments (ссылка)
GET /api/tasks Получение списка всех задач -
GET /api/tasks/{id} Получение задачи по ID id (в URL)
PUT /api/tasks/{id} Обновление задачи id (в URL), description, category, status, priority, assigned_to, attachments (ссылка)
DELETE /api/tasks/{id} Удаление задачи id (в URL)
PATCH /api/tasks/{id}/status Изменение статуса задачи id (в URL), status
PATCH /api/tasks/{id}/assign Назначение исполнителя id (в URL), assigned_to
